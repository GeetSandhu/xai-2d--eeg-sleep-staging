# xai-2d--eeg-sleep-staging
Source code for "Towards Explainable Sleep Stage Classification using Single-Channel Electroencephalogram": IEEE BIBM 2026 Workshop (AgIA4BioHealth). Built on top of the SleepXAI framework (Dutt et al., 2023). Extends XAI evaluation to five attribution methods (Grad-CAM, Saliency, DeepLIFT, SHAP, IG) .
